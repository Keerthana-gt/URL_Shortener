# URL Shortener

A simple C++ project that shortens long URLs into short codes and expands them back to the original link.  
This project demonstrates basic data structures, hashing, and string manipulation in C++.

---

## 🚀 Features
- Shorten any given URL into a random 6‑character code.
- Expand a short code back to the original URL.
- Error handling for invalid codes.
- Unit tests included to verify correctness.

---

## 📂 Project Structure
- `include/` → Header files (`shortener.h`)
- `src/` → Source code (`main.cpp`, `shortener.cpp`)
- `tests/` → Unit tests (`test_shortener.cpp`)
- `docs/` → Documentation files
